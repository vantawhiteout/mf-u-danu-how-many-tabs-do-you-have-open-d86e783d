## What it does

`main.ts` writes a single number, `4`, to `/output/entry.txt` and verifies the
bytes it wrote. The whole entry is the repository at the submitted commit:
no network calls, no secrets, no files read from outside the repository.

Run it with Node 22 or newer:

```sh
node main.ts
```
